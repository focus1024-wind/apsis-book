# 轨道摄动

开普勒轨道是永远重复的椭圆，真实轨道不是。除地球质点引力之外的各种力会使椭圆变形并改变其朝向。本文档列出这些力，并说明本工作区中各模型包含其中哪些。

## 定义

摄动是除中心质点引力外作用于卫星的任何加速度。对低地球轨道，主要项按量级大致排列如下：

| 摄动 | 来源 | 低地球轨道的典型量级 | 性质 |
|------|------|----------------------|------|
| 扁率 `J2` | 地球不是球体 | 中心引力的 `1e-3` | 在升交点与近地点上为长期项 |
| 大气阻力 | 残余大气 | 中心引力的 `1e-7` 至 `1e-4`，取决于高度与太阳活动 | 轨道长期衰减 |
| 三体引力，日月 | 日月引力 | 低轨为 `1e-6`，高轨更大 | 长周期 |
| 太阳光压 | 光子动量 | 中心引力的 `1e-9` 至 `1e-8` | 长周期，取决于面积与质量 |
| 高阶带谐与田谐 | 地球引力场 | 递减级数 | 长期与共振 |
| 相对论效应 | 广义相对论 | 低轨为中心引力的 `1e-9` | 在升交点上为长期项 |
| 潮汐与固体潮 | 地球形变 | 低于以上各项 | 长周期 |

上表按对低地球轨道影响的大小排列，该顺序随高度变化：在数千公里以上三体项超过阻力，且与地球引力场的共振成为主导的长周期效应。

## 数学含义

中心引力为

```text
a_central = -mu r / |r|^3
```

描述赤道隆起的一阶带谐项 `J2` 为

```text
a_J2 = -1.5 J2 mu R^2 / r^5 *
       [ x (1 - 5 z^2/r^2), y (1 - 5 z^2/r^2), z (3 - 5 z^2/r^2) ]
```

其中 `R` 是赤道半径，`z` 沿自转轴量取。它没有改变能量的分量，因此一阶上不影响轨道大小，改变的是轨道朝向。其长期效应为

```text
dOmega/dt = -1.5 n J2 (R/a)^2 cos(i) / (1 - e^2)^2
domega/dt =  0.75 n J2 (R/a)^2 (5 cos^2(i) - 1) / (1 - e^2)^2
```

前者使小倾角轨道缓慢向西进动，使极轨轨道在赤经上进动。两者都大到在一天之内即可产生影响。

阻力不是保守力。它带走能量与角动量，从而降低半长轴与偏心率。其大小取决于大气密度，而大气密度强烈依赖高度与太阳活动。SGP4 用单个拟合参数 `BSTAR` 建模该效应，而不是使用密度模型。

三体引力与太阳光压对高轨是一阶效应，无法用单个拟合参数刻画，在力模型传播器中通过数值积分处理。

## 单位约定

- 使用力模型时加速度单位为**千米每二次方秒**；本文档为便于阅读用相对中心引力的无量纲比值表示。
- 带谐系数如 `J2` 为**无量纲**，其缩放所用参考半径单位为**千米**。
- `BSTAR` 单位为**地球半径的倒数**。

## 适用边界

包含哪些摄动取决于高度与区间，而不是某条固定规则：

- **数小时，任意轨道。** 中心引力与 `J2` 足以应付除精确测距外的一切。
- **数天，低地球轨道。** 必须包含阻力，其不确定性是主导误差。
- **数天，地球静止轨道。** 必须包含三体引力与太阳光压；阻力可忽略。
- **数周或更长。** 任何模型的不确定性都超过它试图刻画的效果，结果应视为误差不断增长的预测。

SGP4 通过把其所建模的摄动拟合到元素集，替调用方做出了这一选择。这既是它的强项也是它的限制：它总是与元素一致，但无法表示拟合未包含的力。

## 各模型包含内容对比

| 摄动 | 二体 | SGP4 | SDP4 | 力模型积分 |
|------|------|------|------|------------|
| 中心引力 | 是 | 是 | 是 | 是 |
| `J2` 扁率 | 否 | 是，长期项 | 是，长期项 | 是，完整场 |
| 阻力 | 否 | 是，单个拟合项 | 是，单个拟合项 | 是，配密度模型 |
| 三体引力 | 否 | 否 | 是，长周期 | 是 |
| 太阳光压 | 否 | 否 | 否 | 是 |
| 与地球引力场的共振 | 否 | 否 | 是 | 是，在引力场中 |
| 高阶带谐与田谐 | 否 | 否 | 部分 | 是 |
| 相对论效应 | 否 | 否 | 否 | 可选 |
