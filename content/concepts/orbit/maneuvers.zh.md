# 轨道机动

机动改变轨道。卫星位于一条闭合曲线上的某一点，最终必须到达另一条不同的闭合曲线上的另一点，而这一改变要用推进剂买单。这就是主题：改变有多大、代价多少，以及轨道不是圆形时代价如何变化。

## 定义

**速度增量**（delta-v）是速度改变的大小。机动被规划为一系列速度增量，推进剂代价由火箭方程按其总和导出。

**脉冲**在零时间内施加全部改变。当点火时间相对轨道周期很短时它是正确的模型；对低地球轨道而言这意味着短于一分钟的任何点火。

**有限推力**在足够长的时长上施加推力，此时卫星在推力期间仍在移动。这一区分并非学术问题：电推进辅助的低轨转移可以持续数小时，其重力损失占理想代价的相当部分。

## 数学含义

### 火箭方程

飞行器能产生的速度取决于推进剂的喷气速度和质量比：

```text
delta_v = v_e * ln (m_0 / m_f)
```

其中 `v_e` 为喷气速度。由于对数函数增长缓慢，推进剂加倍远不能使速度加倍。这就是任务的速度增量是设计首要约束的原因，也是分级存在的原因。

### 霍曼转移

在两个共面圆轨道之间，最省的两脉冲转移就是霍曼转移。第一次点火把远地点或近地点抬升或降低到与目标一致，卫星滑行半个周期，第二次点火圆化。

设 `r_1`、`r_2` 为两个半径、`a_t = (r_1 + r_2) / 2` 为转移半长轴，两次点火由活力公式给出：

```text
delta_v_1 = sqrt( mu (2/r_1 - 1/a_t) ) - sqrt( mu / r_1 )
delta_v_2 = sqrt( mu / r_2 ) - sqrt( mu (2/r_2 - 1/a_t) )
```

滑行时间取转移椭圆周期的一半：

```text
t_coast = pi sqrt( a_t^3 / mu )
```

从 300 km 转移到地球静止轨道约需 4.1 km/s，它占运载器可提供能力的很大一部分，且其中大部分来自第一次点火。

### 变轨面

同时改变倾角的转移比共面转移更贵。在同一次点火中既抬升远地点又转动轨道面的联合机动，代价高于单独做其中任一项。给定半径改变与倾角改变时，最优解是一个两次点火的序列，其中变轨面在较小半径处完成，因为该处速度最低，同样的角度转动在速度增量上最便宜。

```text
delta_v_plane ~ V * 2 sin( 倾角改变量 / 2 )
```

其中 `V` 是完成转动处半径上的圆轨道速度。

### 有限推力

在有限推力过程中，卫星仍在抵抗重力运动，且推力不沿瞬时速度方向。实际达到的速度增量小于理想的 `a * t`，差值即重力损失：

```text
重力损失 = | 理想 delta_v | - | 实际 delta_v |
```

它随点火时长增长。化学推力点火足够短，可以忽略；电推进不行。

## 单位约定

- 速度增量与速度：千米每秒。
- 半径：千米。
- 引力参数 `mu`：立方千米每二次方秒。
- 倾角：弧度；在正弦中使用度会隐藏约 57 的因子。

## 适用边界

霍曼转移只在共面圆轨道之间、且只在两脉冲转移之中最优。真实任务很少如此：轨道是椭圆的、倾斜的，或两者兼有；当两个半径之比超过约 11.94 时，双椭圆转移可以优于霍曼，代价是飞行时间要长得多。

脉冲模型在点火占轨道周期很小比例时是充分的。对电推进的螺旋升轨并不充分，那时"点火"就是整个任务。

变轨面很少值得做。为到达不同星下点而抬高倾角，代价与倾角成正比，常常超出整个运载预算，因此轨面在发射时选定并维持，而不是更改。
