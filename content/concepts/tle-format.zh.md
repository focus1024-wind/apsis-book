# 两行元素格式

两行元素集（TLE）是一种定宽文本记录，描述已编目卫星的平均轨道。它是编目机构发布的格式，也是 SGP4 传播器所拟合的输入。本文档给出布局、校验和规则与单位。

## 定义

两行元素集包含一个可选的名称行，后接两行数据，通常称为第 1 行和第 2 行。每个字段占据固定的列范围，列从 1 开始编号。每行数据以一个校验位结尾。

```text
ISS (ZARYA)
1 25544U 98067A   08264.51782528 -.00002182  00000-0 -11606-4 0  2927
2 25544  51.6416 247.4627 0006703 130.5360 325.0288 15.72125391563537
```

## 字段布局

第 1 行：

| 列 | 字段 | 单位 |
|----|------|------|
| 1 | 行号，恒为 `1` | |
| 3-7 | 卫星编目号 | |
| 8 | 密级，`U`、`C` 或 `S` | |
| 10-17 | 国际编号 | |
| 19-32 | 历元，两位年与年内小数日 | 年、年内日 |
| 34-43 | 平均运动一阶导数的二分之一 | rev/day^2 |
| 45-52 | 平均运动二阶导数的六分之一 | rev/day^3 |
| 54-61 | `BSTAR` 阻力项 | 1 / 地球半径 |
| 63 | 星历类型 | |
| 65-68 | 元素集编号 | |
| 69 | 校验位 | |

第 2 行：

| 列 | 字段 | 单位 |
|----|------|------|
| 1 | 行号，恒为 `2` | |
| 3-7 | 卫星编目号 | |
| 9-16 | 倾角 | 度 |
| 18-25 | 升交点赤经 | 度 |
| 27-33 | 偏心率，隐含小数点 | 无量纲 |
| 35-42 | 近地点幅角 | 度 |
| 44-51 | 平近点角 | 度 |
| 53-63 | 平均运动 | rev/day |
| 64-68 | 历元时的圈数 | |
| 69 | 校验位 | |

## 两个容易误读的约定

**指数字段带有隐含小数点。** 指数字段写作：尾数符号、不含小数点的尾数、指数符号、一位指数数字。尾数的读取方式是在其第一位数字前放置小数点。因此

```text
 12345-3  表示  0.12345e-3
-11606-4  表示 -0.11606e-4
```

**偏心率带有隐含小数点。** 字段 `0006703` 表示 `0.0006703`，不是 `6703`。

完全空白的字段表示零，这是格式书写缺省项的方式。

## 数学含义

一行的校验和是该行十进制数字之和，加上每个负号计一，再对十取模：

```text
checksum = (数字之和 + 负号个数) mod 10
```

只有前 68 列参与；校验位占据第 69 列，不计入自身的和。示例第 1 行的和为 167，校验位为 7。

历元写作两位年与该年内的分数日。两位年的展开约定为：`57` 至 `99` 属于二十世纪，`00` 至 `56` 属于二十一世纪，这样分界点位于卫星编目的起点之前。

## 单位约定

格式本身不自描述，其单位是固定的：

- 姿态角单位为**度**。
- 平均运动单位为**圈每天**。
- 平均运动导数对应**天**的相应次幂。
- `BSTAR` 单位为**地球半径的倒数**，地球半径是传播器使用的赤道半径（千米）。
- 偏心率为**无量纲**。
- 历元是一个 **UTC** 时刻。

解析器保留格式的单位。到弧度与弧度每分钟的换算发生在传播器中，而不是解析器中，因此从解析结果读到的值与文件所写的完全一致。

## 适用边界

两行元素集描述的是**平均**元素，不是瞬时元素。这些数字是 SGP4 模型的输入，只有与该模型一起使用才有意义。把它们交给二体传播器会得到不同且错误的结果。

格式中没有元素集精度的字段，也没有指明所用传播模型的字段。SGP4 是该模型的约定是格式之外的。这两点都说明，应把元素集与其来源及所用模型一起保存。

两行元素集在其历元附近的一段区间内有效。传播器包含一个模拟轨道在区间内衰减的阻力项，模型可用的区间视高度与太阳活动而定，从数天到数周不等。

## 元素格式对比

| 格式 | 内容 | 拟合模型 | 精度 | 此处采用 |
|------|------|----------|------|----------|
| 两行元素集 | 平均元素与阻力项 | SGP4 与 SDP4 | 数天内公里级 | 是 |
| CCSDS OEM | 时间网格上的位置速度或元素 | 任意 | 米级 | 否 |
| CCSDS OPM | 单一历元的位置与速度 | 任意 | 米级 | 否 |
| SP3 | 规则网格上的卫星位置 | 任意 | 厘米至米级 | 否 |
| 广播星历 | 开普勒元素加改正 | GNSS 轨道模型 | 米级 | 否 |
| 精密星历 | 网格上的位置与钟差 | 后处理 | 厘米级 | 否 |

两行格式是这些格式中精度最低而可获得性最广的，这正是它重要的原因。
