# 参考系

只有当测量所在的参考系已知时，一组数才是位置。内核使用两个参考系：一个固定在惯性空间，一个与旋转的地球固连。本文档定义它们以及二者之间的变换。

## 定义

| 参考系 | 原点 | 坐标轴 | 随地球旋转 |
|--------|------|--------|------------|
| ECI，地心惯性系 | 地心 | J2000.0 的平赤道与平春分点 | 否 |
| ECEF，地心地固系 | 地心 | 随地球旋转 | 是 |
| 大地坐标 | 椭球面上 | 纬度、经度、高 | 是 |

固连于地面的点在 ECEF 中坐标恒定，而在 ECI 中绕原点旋转。固定在惯性空间中的矢量（如指向遥远恒星的方向）在 ECI 中坐标恒定。

内核把参考系附着在类型上。`Eci`、`Ecef` 与 `Geodetic` 是不同的类型，因此表示在某一系中的位置不能传给期望另一系的接口。转换是显式的方法调用。

## 数学含义

惯性系与地固系之间的变换是绕第三轴旋转地球自转角：

```text
r_ecef = R3(theta) r_eci
r_eci  = R3(theta)^T r_ecef
```

其中 `theta` 是地球自转角，`R3` 是旋转矩阵

```text
R3(theta) = [ cos(theta)   sin(theta)  0
             -sin(theta)   cos(theta)  0
              0            0           1 ]
```

该旋转是正交的，因此保持长度与夹角不变。这是一个有用的校验：某次转换使矢量长度变化超过舍入误差就说明有误。

地固系直角坐标与大地坐标之间的变换不是旋转，因为椭球不是球。它由 [[geodesy-wgs84]] 中描述的闭式解求得。

## 单位约定

- `Eci` 与 `Ecef` 中的直角坐标单位为**米**。
- 传播器惯性系中的速度单位为**千米每秒**，位置单位为**千米**；轨道层采用元素集与 SGP4 理论所用的单位。
- 大地纬度与经度单位为**弧度**，高为椭球面以上的**米**。

坐标层用米而轨道层用千米，这是有意为之而非疏漏：各自遵循所实现理论的惯例。层之间的转换是一次显式乘法，不是隐式的。

## 适用边界

惯性系是一种理想化。此处使用的参考系与 J2000.0 的平赤道平春分点对齐，并被视为惯性系，忽略了岁差与章动。在元素集的有效区间内（数天），被忽略的运动远低于传播精度；在数年的尺度上则不然，此时调用方需要使用建模了岁差与章动的参考系实现。

地球自转角定义了参考系之间的旋转，但不包含极移，即自转轴在地球内部的微小运动。极移小于 0.5 角秒，约合地面 15 米，此处忽略。

## 参考系约定对比

| 约定 | 坐标轴定义 | 包含岁差 | 包含章动 | 此处采用 |
|------|------------|----------|----------|----------|
| J2000.0 惯性系 | 2000-01-01 12:00 TT 的平赤道平春分点 | 否 | 否 | 是 |
| 当日真赤道系 | 当日的真赤道真春分点 | 是 | 是 | 否 |
| 当日平赤道系 | 当日的平赤道平春分点 | 是 | 否 | 否 |
| TEME，真赤道平春分点 | 真赤道、平春分点 | 隐含 | 对极轴为是 | 是，作为 SGP4 的输出 |
| 地固系 | 随地球旋转 | 不适用 | 不适用 | 是 |
| ITRF | 地固系的一种实现 | 不适用 | 不适用 | 以 WGS 84 近似 |

TEME 是两行元素集所针对的坐标系。它是 SGP4 的输出，与 J2000.0 惯性系不同。从 TEME 转换到地固系需要地球自转与春分点方程，后者是平春分点与真春分点之间的小角度。
